Credits

WoW Companion uses other people's work. Thanks to everyone below.

Game data

  • Everloot. Loot sources, quests players have seen and vendor offers come from Everloot's public data. "Data from Everloot (https://everloot.app), CC BY-SA 4.0."
  • wago.tools. Facts from the game client's own tables, such as ids, numbers and names, were retrieved via wago.tools. Credit: "Blizzard game client data, retrieved via wago.tools". The underlying game data is Blizzard's. We publish facts only, never long text.

Questie

Questie is a popular quest addon. If you have it installed, WoW Companion reads it on your own PC to find quest locations. We never copy it, and none of its code or data is in our files. Without it, the app uses the addon's data and the game data alone.
